# tech-hotwords

本地语音输入用的科技词包。只收 AI 模型和产品、开发工具、协议、芯片与硬件；收录 2025 年以来发布或在开发者圈流行的词，不收互联网通用热词。每包最多 150 词，每行一个，UTF-8，# 开头是注释。人名、个人资料不应提交。

词表为 CC0 1.0。欢迎 issue 或 PR；由维护者审核合并。校验脚本检查重复词、词数、编码和索引，main 推送通过后发布 Release。客户端只下载 Release 附件。

初版来源见 SOURCES.md；时间范围含“2025 年后走红”，不表示所有产品首次发布于 2025 年。版本和写法请以官方链接为准。

本仓库初始词表由 AI 整理，后续条目由维护者审核。
